# Juego del Ahorcado

Aplicación sencilla del clásico juego del ahorcado.

## Instrucciones

- Se selecciona una palabra secreta al iniciar la partida.
- Introduce letras para intentar adivinar la palabra.
- Cada fallo resta una vida.
- Si aciertas todas las letras, se muestra la página **ganado.php**.
- Si pierdes todas las vidas, se muestra la página **perdido.php**.
- En ambas páginas puedes volver a empezar la partida con un botón que redirige a **index.php**.

## Estructura

- `index.php`: página principal del juego.
- `ganado.php`: página mostrada al ganar.
- `perdido.php`: página mostrada al perder.
- `css/style.css`: estilos de la aplicación.

## Reiniciar partida

Puedes reiniciar la partida desde cualquiera de las páginas finales usando el botón “Jugar de nuevo”.
